# Dilyyas Bday

**Сайт:** https://13e01.github.io/dilyyas-bday/

Персональный birthday wishlist Дили: одна страница с главным экраном, четырьмя разделами подарков
(подарки своими руками, цветы, картины, деньги) и просмотром фото на весь экран.
Чистый HTML / CSS / JavaScript — без сборки, сервера и зависимостей (кроме шрифтов Google Fonts).

## Структура

```text
dilyyas-bday/
├── index.html              страница
├── css/style.css           все стили
├── js/content.js           ВЕСЬ контент: тексты, главное фото, списки фотографий
├── js/main.js              отрисовка разделов, анимации появления, просмотр фото
├── assets/
│   ├── images/
│   │   ├── handmade/       оптимизированные копии HM-фото (hm-01.jpg + hm-01-sm.jpg …)
│   │   ├── flowers/        копии FL-фото
│   │   └── art/            копии ART-фото
│   └── icons/favicon.svg
├── HM*.jpeg/PNG, FL*…, ART*…   оригиналы, не изменялись
└── README.md
```

Для каждого фото есть две копии: `*.jpg` (до 1100 px по ширине, для просмотра) и `*-sm.jpg`
(560 px, для галереи на телефоне).

## Локальный запуск

Можно просто открыть `index.html` двойным кликом. Удобнее — через локальный сервер из папки проекта:

```bash
npx serve .
```

или

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000` (для `npx serve` — адрес, который он покажет).

## Как заменить главное фото Дили

Сейчас используется `assets/images/hero/dila.jpg` (960 px) и `dila-sm.jpg` (640 px, для телефонов),
сконвертированные из оригинала `DILA-PHOTO.HEIC` (он в репозиторий не попадает).

1. Положите новое фото в `assets/images/hero/` (вертикальное, JPEG/WebP, ~960 px по ширине, до 400 КБ).
2. В `js/content.js` укажите путь (и размеры, если знаете):

   ```js
   heroPhoto: {
     src: "assets/images/hero/dila.jpg",
     srcSmall: "assets/images/hero/dila-sm.jpg",
     width: 960,
     height: 1287,
     alt: "Диля на улице города"
   },
   ```

Если `src` оставить пустым (`""`), вернётся графитовая заглушка. Фото обрезается по рамке 4:5 с аркой сверху (`object-fit: cover`),
поэтому лицо лучше держать ближе к центру кадра.

## Как добавить, убрать или переставить подарки

Все списки — в `js/content.js`, в массиве `categories`. Каждое фото — одна строка:

```js
{ src: "assets/images/flowers/fl-07.jpg", srcSmall: "assets/images/flowers/fl-07-sm.jpg", width: 1080, height: 1350, alt: "Короткое описание фото" },
```

- `src` — обязательно; `srcSmall`, `width`, `height` — по желанию (размеры убирают «прыжки» при загрузке).
- Порядок строк = порядок на сайте. Удалить фото — удалить строку.
- `alt` — короткое описание для незрячих пользователей.
- Тексты (`title`, `tagline`, `intro`, `footer`, текст раздела «Деньги») меняются там же.

## Префиксы файлов

| Префикс | Раздел                    | Папка копий                |
|---------|---------------------------|----------------------------|
| `HM`    | Подарки своими руками     | `assets/images/handmade/`  |
| `FL`    | Цветы                     | `assets/images/flowers/`   |
| `ART`   | Картины                   | `assets/images/art/`       |

Раздел «Деньги» не использует фото — это декоративный конверт.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `dilyyas-bday`).
2. Из папки проекта:

   ```bash
   git init
   git add .
   git commit -m "Dilyyas Bday"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/dilyyas-bday.git
   git push -u origin main
   ```

3. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<ваш-логин>.github.io/dilyyas-bday/`.

Все пути относительные, поэтому сайт работает и в подпапке репозитория.
Оригиналы фото (`HM*`, `FL*`, `ART*` в корне) исключены через `.gitignore` и в репозиторий не попадают —
публикуются только оптимизированные копии из `assets/images`.

## Как обновить сайт

1. Измените файлы (например, `js/content.js` или добавьте фото в `assets/images/...`).
2. Отправьте изменения:

   ```bash
   git add .
   git commit -m "Описание изменений"
   git push
   ```

3. GitHub Pages пересоберёт сайт автоматически за 1–2 минуты
   (статус — во вкладке **Actions** репозитория). Если изменения не видны, обновите страницу без кэша.
